# Snake Water Gun Game

A simple Python mini-project where the player plays the classic "Snake, Water, Gun" game against the computer.

## About the Project

This project was built while learning Python and is a beginner-friendly game logic exercise. The game compares the player's choice with a random choice made by the computer and determines the winner.

## Game Rules

- Snake beats Water
- Water beats Gun
- Gun beats Snake

## How to Play

1. Run the Python script.
2. Enter one of the following choices:
   - `snake`
   - `water`
   - `gun`
3. The computer randomly selects its move.
4. The program displays both choices and announces the result.
